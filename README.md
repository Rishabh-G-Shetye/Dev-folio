# 🚀 My Developer Portfolio

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://YOUR-APP-URL.streamlit.app)
![Python](https://img.shields.io/badge/Python-3.9%2B-blue)

A dynamic, automated portfolio website built with Python and Streamlit. It fetches my latest projects directly from the GitHub API, ensuring my portfolio is always up-to-date.

**[👉 View Live Demo](https://YOUR-APP-URL.streamlit.app)**

## 🌟 Features
* **Automated Project Fetching:** Connects to GitHub API to display pinned or recent repositories.
* **Responsive Grid Layout:** Clean, card-based UI using Streamlit containers.
* **Profile Sidebar:** Displays bio, skills, and social links.
* **Pure Python:** No HTML/CSS knowledge required to maintain.

## 🛠️ Tech Stack
* **Frontend:** [Streamlit](https://streamlit.io/)
* **Data:** GitHub REST API
* **Language:** Python 3

## 💻 How to Run Locally

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/my-portfolio.git](https://github.com/YOUR_USERNAME/my-portfolio.git)
    cd my-portfolio
    ```

2.  **Install dependencies**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the app**
    ```bash
    streamlit run app.py
    ```

## 🚀 Deployment
This app is optimized for **Streamlit Community Cloud**.
1.  Push code to GitHub.
2.  Log in to [share.streamlit.io](https://share.streamlit.io).
3.  Select the repo and deploy!
